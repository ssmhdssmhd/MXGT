# MXGT

> 视频资源聚合 + 苹果 CMS v10 对接 + JSON 解析路由 + 在线播放页的综合后台
> 版本：v0.0.6

## ✨ 特性

- 🖥️ 在线播放页：`?url=xxx` 动态渲染，API 地址不硬编码（query / localStorage / 同域 三层兜底）
- 🛰️ JSON 解析路由：JSONPath / Regex / Custom 三种提取器 + Redis 缓存 + proxy 防盗链转发
- ⚙️ 苹果 CMS v10 兼容输出（`/api.php/provide/vod/`）
- 🎛️ 管理后台侧边栏（11 个模块）：仪表盘 / 前端设置 / 分析设置 / **AI 设置** / 匹配设置 / 调用设置 / 映射设置 / 解析规则 / 影片管理 / 更新设置 / 管理员
- 🤖 AI 设置：m3u8 智能分析 ts 分片，MD5 指纹库识别视频内嵌广告/字幕/插播，内置播放器实时标注，去广告 m3u8 动态生成
- ☁️ **GitHub Actions 云端编译**：自动编译多平台 Go 可执行文件并发布 Release
- 📦 **免配置运行**：下载单文件即用，无需 Go / MySQL / Redis / Docker
- 🗂️ **运行目录自建环境**：配置、数据、日志全部自动创建在运行文件夹内
- 🔄 **替换即更新**：更新只需替换可执行文件，配置与数据保留

## 🚀 快速开始（免配置）

> 由 GitHub Actions 云端编译，无需安装任何环境。

```
1. 到 GitHub Releases 下载对应平台的可执行文件
   （linux-amd64 / linux-arm64 / windows-amd64 / darwin-amd64 / darwin-arm64）
2. 放到任意目录（该目录即「运行文件夹」）
3. 双击 或 ./mxgt 启动
4. 浏览器打开 http://localhost:8080
```

首次启动自动完成：

- 生成 `config.yaml`（带注释的默认配置）
- 自动创建运行目录结构（`data/` SQLite 数据库、`cache/`、`logs/`、`uploads/`、`tmp/`）
- 默认内嵌 SQLite（零数据库配置）；在 `config.yaml` 配置了 MySQL / Redis 才自动切换
- 打印访问地址 + 默认管理员账号提示

```
run/  ← 运行文件夹
├── mxgt          ← 可执行文件（更新时只替换这一个）
├── config.yaml   ← 用户配置（首次运行自动生成，升级保留）
├── data/         ← SQLite 数据库（默认）
├── cache/        ← 本地缓存（无 Redis 时降级用）
├── logs/         ← 运行日志
└── uploads/      ← 上传文件
```

## 🔄 更新方式

| 方式 | 步骤 |
|---|---|
| 后台一键更新 | 管理后台「更新设置」→ 检查更新 → 一键下载 → 自动备份旧版 → 替换执行文件 → 重启 |
| 手动替换 | 下载新 Release 可执行文件 → 覆盖运行目录里的 `mxgt` → 重启 |

更新后 `config.yaml` / `data/` / `uploads/` 全部保留，**替换执行文件即完成升级**。

## 🧠 设计原则

1. 云端编译：所有构建在 GitHub Actions 完成，用户不接触编译
2. 免配置运行：单文件下载即用，首次运行自动建环境
3. 运行目录隔离：配置/数据/日志全在运行文件夹内，卸载即删文件夹
4. 替换即更新：更新只换执行文件，数据保留
